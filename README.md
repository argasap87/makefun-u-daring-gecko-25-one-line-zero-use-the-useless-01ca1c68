## The line

> I can read any mind on Earth — but only in a language that went extinct in 1402.

Mind-reading is the classic dream power — ruined by the small print. The flaw is specific, vivid, and pays off in the last few words: fluency in a language nobody has spoken for six centuries helps absolutely nobody, including the owner.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (creating the directory if needed).
